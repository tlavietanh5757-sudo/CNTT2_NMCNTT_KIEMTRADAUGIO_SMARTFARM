# HƯỚNG DẪN CHẠY SCRIPT (CODE BLOCK)

**INPUT**: là dữ liệu và tham số cần cung cấp cho hệ thống trước khi chạy: 
VD: từ khoá cần tìm kiếm "ERROR", file log gốc

**PROCESS**: là quá trình hệ thống xử lý dữ liêu
VD: tìm các từ khoá theo yêu cầu, lọc dữ liệu

**OUTPUT**: là kết quả cuói cùng hệ thống in ra màn hình:
VD kết quả tìm kiếm đươc
